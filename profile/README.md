## What is Vex V5 Robotics?

VEX V5 Robotics is a robotics competition designed to help high school and college students (VEX U) learn building, coding, notebooking, and the engineering design process through hands-on experience. VEX V5 Robotics also allows teams and students to go more in-depth on individual aspects. For example, in autonomous coding, students can start with easy drag-and-drop block coding or step up to professional programming languages such as C++ and Python to make their creations fully autonomous.
